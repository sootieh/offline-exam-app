# 考神 PWA · 离线刷题 App

一个可以**装到 iPhone 主屏幕**上用的离线刷题 App。导入自己的题库，随时随地进行顺序/随机练习、背题、限时模拟考试，自动收拾错题本。

- **GitHub Pages（官方托管）**：https://sootieh.github.io/offline-exam-app/
- 备用镜像：https://exam-quiz-app-25951.app.workbuddy.host/
- 无需 Xcode、无需 Apple 开发者账号；**数据全部存在手机本地，不上传任何服务器**

---

## 功能

| 模块 | 说明 |
| --- | --- |
| 题库导入 | Excel（支持多工作表）、Word（.docx，含表格排版）、CSV、TXT、JSON，或直接粘贴文本智能识别 |
| 题型 | 单选、多选、判断、填空，导入时自动识别；也支持在「题型」列里手动指定 |
| 刷题 | 顺序 / 随机刷题，可按「全部 / 未做 / 错题 / 收藏 / 未掌握」与题型双重筛选；**取消「确认作答」**——翻到下一题/上一题、滑动翻页、题卡跳转或退出时，当前题自动判为已作答（静默判分、不弹解析）；**判分后仍可修改答案**（旁有「已作答 · 可修改」提示，选项只高亮上次作答项、不提前标出正确答案），改动即撤销上一轮记录并按新答案重新判分，正确率与错题数不会重复累加；**随机全量刷题默认从上次中断处开始**（toast 上带「重新开始」），题库页与刷题页也有继续卡片；题面下方自带可折叠「答案解析」卡（默认折叠，可随时点开看我的答案 / 正确答案 / 参考解析）；中途退出可「继续」或「重新开始」 |
| 错题 | 题库页「错题重做」按钮或点「当前错题」统计卡进入（推入页，带返回键）：列出错题与解析（点按展开），展开后有「✓ 已掌握，移出错题本」按钮，一键重做，底部「清空错题」一键清空错题本（保留练习次数与正确率） |
| 题库主页 | 顶栏「题库下拉框 + 导入按钮」同一行；题库**只在此处选择**，刷题 / 考试 / 错题页全部沿用，不再各自选择题库 |、继续上次练习、开始刷题 / 随机练习 / 模拟考试快捷入口、已练 / 错题 / 正确率 / 收藏统计卡与题型进度 |
| 模拟考试 | 按题型自定义题量与时长，倒计时到点自动交卷；多选漏选记半分；交卷后逐题回顾，保留历史成绩 |
| 错题本与收藏 | 错题自动收集，可单独重做、一键清空；收藏页（点题库页「收藏」统计卡进入）可练习收藏、逐题取消收藏、一键**清空收藏** |
| 题库管理 | 题库页「题库管理」进入**统一视图**：列出全部题库（题量/已练），**按住 ⠿ 可拖动排序**（顺序同步到题库下拉框），每行有**合并 / 删除**操作，底部有**导入题库**按钮 |
| 题库管理 | 每个题库支持重命名与删除（题库卡片右上角「⋯」或题库详情页），删除需二次确认 |
| 统计 | 题库页内嵌已练 / 错题 / 正确率 / 收藏统计卡与题型进度；「完整统计」含近 14 天练习量图表、分题型掌握情况 |
| 界面风格 | 5 套低饱和度主题（墨绿 / 雾蓝 / 陶土 / 石墨 / 黛紫），在「设置 → 界面风格」切换，跟随系统深色模式 |
| 答题偏好 | 「自动跳下一题」（单选题、判断题选定后直接跳转下一题）、「上下滑动翻题」、「左右滑动翻题」三个开关，均在「设置 → 答题与翻题」中，可随时关闭 |
| 应用更新 | 设置 → 「强制刷新 PWA」：清除离线缓存、注销 Service Worker 并带时间戳重新加载，解决打开后看不到新版本的问题 |
| 应用图标 | 12 款图标在「设置 → 应用图标」切换：极简对勾 / 星辰 / 勋章 三种图案 × 微信绿 / 支付宝蓝 / HA 天蓝 / 白色 四种底色；已添加到主屏幕的图标需删除后重新添加才会更新（iOS 限制） |
| 启动速度 | 930KB 的 Excel 解析库按需加载（仅导入 Excel 时才下载），主脚本 `defer` 并行加载；Service Worker 网络请求 1.5 秒超时保护，弱网直接用缓存版本 |
| 数据安全 | 一键导出 / 恢复 JSON 备份，换手机不丢数据 |

## 在 iPhone 上安装

1. iPhone 用 **Safari** 打开部署好的链接（iOS 上只有 Safari 支持添加到主屏幕）
2. 点底部「分享」按钮 → 向下找到 **添加到主屏幕** → 添加
3. 桌面出现独立图标，点开即全屏运行，**断网也能刷题**

> 首次打开后 Service Worker 会缓存全部资源，之后飞行模式也能用。题库数据存在 IndexedDB 里。

## 题库格式

### Excel / CSV
首行是表头，至少要有一列题目，其余列可选。列名会自动模糊匹配（中英文都认）：

| 题目 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 | 题型 | 章节 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 下列哪一项属于行政处罚？ | 罚款 | 拘役 | 罚金 | 管制 | A | 罚款属于行政处罚 | 单选 | 第一章 |

- 等效列名：`题干 / question / stem / title`、`answer / 正确答案`、`explain / 解析`、`type / 题型`、`chapter / 分类`
- 答案写法：`A`、`AB`（多选）、`对 / 错 / √ / ×`（判断）、`1982`（填空）
- **多工作表**：导入时会列出所有 Sheet 及各自识别出的题数，可勾选，并选择「合并为一个题库」或「每个工作表单独建题库」
- 没有表头也能解析：按「题目 / 各选项 / 答案」的先后顺序识别

### Word（.docx）
按段落识别，三种排版都支持：

```
1. 下列哪一项属于行政处罚？
A. 罚款
B. 拘役
C. 罚金
D. 管制
答案：A
解析：罚款属于行政处罚；罚金、拘役、管制属于刑罚。
```

- 无题号也能识别（按「题干 → 选项 → 答案」的顺序自动切题）
- 支持 Word **表格**排版的题库（一行一题）
- 章节标题（如「第一章 法律常识」）会被自动忽略
- 不支持旧的 `.doc`（Word 97-2003），请在 Word 里另存为 `.docx`

### TXT / 粘贴文本
与 Word 段落排版一致，题号可用 `1.` `1、` `1)` 等写法。

### JSON

```json
[
  {
    "stem": "地球绕太阳转",
    "options": ["正确", "错误"],
    "answer": "对",
    "explanation": "常识题",
    "type": "single"
  }
]
```

也接受 `{"questions": [...]}` 结构。`type` 可取 `single / multiple / judge / fill`。

> 导入前会先在页面里预览识别结果（题数、题型分布、前 3 题样例、异常提示），确认无误再入库。

## 本地运行

Service Worker 需要 `https` 或 `localhost` 才能注册，直接双击 `index.html` 打不开离线能力，请用任意静态服务器：

```bash
cd exam-app
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

部署到任何静态托管（GitHub Pages、Vercel、Nginx、对象存储）都可以，把整个目录原样上传即可。

## 目录结构

```
exam-app/
├── index.html              页面骨架
├── manifest.webmanifest    PWA 清单
├── sw.js                   Service Worker（离线缓存）
├── css/app.css
├── js/
│   ├── store.js            IndexedDB 数据层（题库/题目/记录/考试/设置）
│   ├── parser.js           题库解析引擎（Excel/Word/CSV/TXT/JSON + 判分）
│   ├── quiz.js             答题引擎（练习/背题/考试三种模式）
│   └── app.js              路由与页面逻辑
├── icons/                   167/180/192/512 PNG 图标
└── vendor/
    ├── xlsx.full.min.js    SheetJS 0.20.3（Excel 解析）
    └── fflate.min.js       fflate 0.8.2（docx 解压）
```

## 技术说明

- **零构建、零运行时 CDN**：纯原生 HTML/CSS/JS，依赖库已内嵌到 `vendor/`，离线可用
- **存储**：IndexedDB，题库与答题记录都在用户设备上
- **离线**：Service Worker 预缓存应用外壳（cache-first + 后台更新）
- **兼容**：iOS Safari 16.4+ / Chrome / Edge；移动端优先布局，适配 iPhone 安全区
